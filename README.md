# regsensitivityR
This repo contains a crude implementation of regsensitivity (https://github.com/mattmasten/regsensitivity) in R.
The reference is Assessing Omitted Variable Bias when the Controls are Endogenous by Diegert, Masten and Poirier (2026).
https://arxiv.org/abs/2206.02303.

This implementation allows support for sample weights.
